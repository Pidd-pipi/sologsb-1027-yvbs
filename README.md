# 实验流程编写与安全复核工具

面向研究人员和实验室安全复核人员的纯前端工作台。实验步骤、复核批注和冻结版本均保存在浏览器本机，可离线编辑。

## 功能

- 按步骤维护名称、目的、材料、设备、用量、预计时间、危险项、控制措施、安全说明、预期结果和依赖关系。
- 添加、复制、删除、上下移动实验步骤，通过复选框建立前置依赖。
- 修改步骤后自动计算全部下游步骤，提醒受影响的后续步骤和已确认内容。
- 自动识别存在危险项但缺少控制措施或安全说明的步骤，并阻止确认与冻结。
- 提交复核后，复核人可逐条添加批注、标记解决、确认或退回。
- 所有步骤确认且安全信息完整后冻结版本；冻结后只能从该版本创建修订稿。
- 保存多个完整版本快照，比较步骤新增、删除及材料、用量、危险项、依赖等字段变化。
- 完整撤销重做、本地自动保存和 `Ctrl/Cmd+S` 手动保存。

## 离线合并（两个页签断网续写）

- 每个页签是一条独立修订分支，草稿按分支键保存，后保存不再覆盖对方的步骤、批注和确认。
- 重新联机后在「离线合并」页签发现其它页签草稿，或导入/导出草稿 JSON，执行三路合并：
  - **单边改动直接接上**：新增步骤、新增批注、只有一侧修改的字段自动合入。
  - **两边都改则保留两份**：同一步骤的同一字段、同一条批注双方都改过时，挂起冲突并暂存本页值，由人工选择采用本页、采用对端或两份都保留；步骤“删/改”冲突同理。
  - **下游确认立即重算**：步骤、依赖或危险项一变更，全部传递下游的已确认状态立即标记为“确认过期”，复核列表、影响提醒和冻结按钮读取同一份派生结果，过期未重认不能冻结。
  - **冻结基线分叉保护**：一侧基于的冻结版本已被另一侧修订时，以双方共同祖先合并，两条修订分支均保留，绝不从旧快照重写当前底稿，方向冲突人工确认。
  - **失败可重试**：合并是纯计算，写入前任何异常都不动当前草稿；失败记录进入重试队列，可一键重试或放弃。
- 「离线合并」页签内置两个演示场景：标准续写（单边改动 + 字段/批注冲突 + 下游过期）与旧冻结版分叉，另有“模拟合并失败”开关。
- `npm run verify:merge` 可运行合并引擎的 25 项场景验证。

## 技术栈

- React 19 + TypeScript
- Vite
- Blueprint UI (`@blueprintjs/core`、`@blueprintjs/icons`)
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run dev
```

开发服务器监听 `5173`，宿主端口仅由部署映射，源码未写入 `10027`。

## 生产构建

```bash
npm install
npm run build
```

构建产物位于 `dist`。

## Docker

```bash
docker build -t sologsb-1027 .
docker run --rm -p 10027:80 sologsb-1027
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10027`。实验数据仅保存在当前浏览器。
